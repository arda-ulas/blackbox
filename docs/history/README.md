# Build history

The record of how Blackbox was built, kept as it was written. These files are not maintained and may
describe behavior that has since changed; the current documentation is one level up.

- `NN_*_plan.md`: one scoped plan per milestone. The file names come from the week each milestone was
  planned in, and each milestone was closed with a git tag of the same name.
- `08_build_log.md`: what each milestone landed and how it was verified.
- `01_decision_log.md`: dated design decisions.
- `DEMO.md`: the command-by-command tour of the built-in demo agent from the 0.1 releases.
